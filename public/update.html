Instructions d'installation

  1. Cliquez le bouton Telecharger ci-dessus
  2. Ouvrez PowerShell sur votre PC
  3. Restaurez les fichiers originaux avec git :
    cd C:\Users\espacegamers\Desktop\HireNova
    git checkout -- package.json src/app/layout.tsx src/app/manifest.ts src/lib/i18n.ts src/components/auth/auth-modal.tsx src/app/api/auth/reset-password/route.ts
  4. Extrayez le ZIP dans le dossier du projet :
    Expand-Archive -Path "$HOME\Downloads\hirenova-update.zip" -DestinationPath "C:\Users\espacegamers\Desktop\HireNova" -Force
  5. Relancez le serveur :
    cd C:\Users\espacegamers\Desktop\HireNova; bun run dev

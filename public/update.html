2 Placer les fichiers sur votre PC

Ouvrez l'explorateur de fichiers et allez dans :
C:\Users\espacegamers\Desktop\HireNova

Placez chaque fichier dans le bon dossier :

  • logo.svg → dans le dossier public
  • route.ts → dans le dossier src\app\api\auth\reset-password
  • auth-modal.tsx → dans le dossier src\components\auth
  • i18n.ts → dans le dossier src\lib
3 Redémarrer le serveur

1. Allez dans la fenêtre PowerShell où tourne le serveur
2. Appuyez sur Ctrl + C pour l'arrêter
3. Tapez bunx next dev -p 3000 pour le relancer
4. Attendez « Ready in ...ms »
5. Ouvrez http://localhost:3000
6. Appuyez sur Ctrl + Shift + R (hard refresh)

⚠️ Important : Quand vous téléchargez route.ts, renommez-le bien en route.ts (pas update-route.ts).
Même chose pour les autres fichiers — enlevez le préfixe « update- » du nom.

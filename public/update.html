3 Redémarrer le serveur

1. Allez dans la fenêtre PowerShell du serveur
2. Appuyez sur Ctrl + C
3. Tapez : bunx next dev -p 3000
4. Attendez « Ready in ...ms »
5. Ouvrez http://localhost:3000
6. Appuyez sur Ctrl + Shift + R (hard refresh)

💡 Astuce : Si le navigateur affiche toujours l'ancienne version après le redémarrage,
essayez d'ouvrir une fenêtre de navigation privée (Ctrl + Shift + N)
ou videz le cache : Ctrl + Shift + Suppr → cochez « Images et fichiers en cache » → Effacer.

   118→   118→## Phase 10 : Fix page blanche — middleware + next-auth
   119→   119→> Date : 2026-07-26
   120→   120→
   121→   121→### Problème
   122→   122→Page blanche répétée dans le Preview Panel malgré serveur répondant HTTP 200.
   123→   123→
   124→   124→### Diagnostic
   125→   125→1. **`src/middleware.ts` toujours présent** — était censé être supprimé (Phase précédente) car il cause un overhead Edge Runtime sur CHAQUE requête (matcher trop large: `/((?!_next/static|...).*)`). Le warning `⚠ The "middleware" file convention is deprecated` apparaissait dans dev.log.
   126→   126→2. **`.env` sans NEXTAUTH_SECRET ni NEXTAUTH_URL** — next-auth affichait warnings `NO_SECRET` et `NEXTAUTH_URL`, causant des `CLIENT_FETCH_ERROR` répétés sur `/api/auth/session` (7+ erreurs dans la console navigateur).
   127→   127→3. **`next.config.ts` sans headers de sécurité** — les headers étaient seulement dans le middleware (qui devait être supprimé).
   128→   128→
   129→   129→### Correctifs appliqués
   130→   130→1. **Suppression de `src/middleware.ts`** — fini l'overhead Edge Runtime
   131→   131→2. **Ajout des security headers dans `next.config.ts`** (source: `/(.*)` ) :
   132→   132→   - X-Content-Type-Options, X-XSS-Protection, Referrer-Policy, Permissions-Policy
   133→   133→   - X-Frame-Options: ALLOWALL (pour iframe Preview Panel)
   134→   134→   - CSP permissive (frame-ancestors *)
   135→   135→3. **Ajout dans `.env`** :
   136→   136→   - `NEXTAUTH_SECRET=hirenova-dev-secret-2050-secure-key-zai-2026`
   137→   137→   - `NEXTAUTH_URL=http://localhost:3000`
   138→   138→
   139→   139→### Résultat vérifié (agent-browser)
   140→   140→- HTTP 200 en 0.1s
   141→   141→- Page titre : "HireNova — Générateur de CV IA, Lettre de Motivation & Score ATS"
   142→   142→- Body : 9223px / 5984 chars (contenu complet)
   143→   143→- **Console errors : VIDE** ✅
   144→   144→- dev.log : propre, toutes réponses 200, plus de warnings next-auth
   145→   145→
